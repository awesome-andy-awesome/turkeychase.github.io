Speed upgrades give +2 levels instead of +1, and every turkey pays 10x coins — but turkeys start a little faster than you, and an abusive grandma chases you across the map. 3 hits from her and you have to restart. Speed upgrades give +5 levels instead of +1, and every turkey pays 50x coins — but turkeys run 1.5x faster than normal, and two Strict Parents hunt you down at once: one swinging a slipper, one swinging a rolled-up paper. 🎁 Daily Rewards

⚠️ Daily rewards only work if you keep using the same save code — make a new code after you claim, and load your newest code each day. All the rules are at the bottom.

📋 How daily rewards work (please read!)
  • Daily rewards are kept inside your save code. They only work if you keep using the same save code: make a new code every time you finish playing, and load that newest code next time.
  • When you make a save code, it saves the date it was made and the day you last claimed a reward. When you load it on a new day, this pop-up opens so you can redeem your next reward.
  • A new reward unlocks every new day (at midnight, using your device's clock). You can claim one reward per day.
  • You have to claim every day. If you skip a day, your rewards go back to Day 1 — unless you pay coins to restore your streak. The first restore costs 10,000c, and every restore after that costs more.
  • There are 30 days of rewards, and each one is better than the last. The last 5 are INSANE! After Day 30 the rewards start again at Day 1, but your "days in a row" keeps counting for the badges (like Played for 365 days in a row).
  • After you claim a reward, make a new save code. If you close the page without making one, the reward (and the claim) is lost.
  • Loading an older save code takes you back to whatever day that code had, and a brand-new game (no code) starts at Day 1.
  • Closed this by accident? Press 🎁 Daily Rewards (or 🎁 in 3D Mode) to open it again and redeem your reward later.

🧑‍💻 Custom Mods
Code your own mod right here, or upload a .txt mod file (from you or a friend). Mods are written in JavaScript and are remembered on this device. They come back switched off each time you open the game, so turn on the ones you want.

The basics

Your code gets one thing to work with, called game. Start the file with // name: My Mod and // description: ... lines so it gets a name when uploaded. A mod that makes a mistake while running is switched off and shows the error here, and the game keeps going.

Change the rules

game.speedMultiplier = 2
how fast you move (1 is normal)
game.turkeySpeedMultiplier = 0.5
how fast turkeys move
game.catchRadiusBonus = 20
adds to your catch radius
game.coinMultiplier = 3
multiplies coins from every catch
game.coins
your coins (you can read or change it)

Run code when things happen

game.onUpdate(() => {...})
every frame (60 times a second)
game.every(5, () => {...})
every 5 seconds
game.onCatch((turkey, coins) => coins * 2)
when you catch a turkey; return a number to change the coins
game.onSpawn(turkey => {...})
when a new turkey appears
game.onKey('m', () => {...})
when a key is pressed
game.onStop(() => {...})
when the mod is switched off

Draw things

game.onDraw(ctx => {...})
draw on the map using map positions (like game.player.x)
game.onDrawScreen((ctx, w, h) => {...})
draw on top of the screen, for text and scores

ctx is a normal canvas, so ctx.fillRect, ctx.arc, ctx.fillText and friends all work.

Useful things

game.player.x / .y
where you are (you can move yourself too)
game.turkeys
every turkey: t.x, t.y, t.species.name, t.species.value, t.speedMultiplier
game.addTurkey('Golden Turkey', x, y)
add a turkey (x and y are optional)
game.removeTurkey(t) / game.setSpecies(t, 'Diamond')
remove a turkey, or change its type
game.message('Hi!')
floating text above you (game.messageAt(x, y, text) for anywhere)
game.keys['shift']
true while a key is held down
game.distance(a, b) / game.random(1, 10)
handy maths
game.frame / game.world.width
frame counter and map size (1900 × 1200)

Sharing

Press Download as .txt under the code box (or Download .txt on any mod in your list) to save it as a file. You can also press Copy code and paste it into a text file yourself. Anyone can then upload that file here. Only load mods from people you trust, because a mod can change anything in the game, including your coins.

🛒 Shop

🪙 You have 0 coins

🎒 Everything you buy goes into your hotbar. Hold it (press its number or click it) and click to eat it. Eat for a short boost. Bigger meals cost more but give bigger multipliers. Different foods stack, and eating the same food again adds more time.

🎒 Weapons go into your hotbar. Hold one, then click the map to use it: bombs are thrown where you click, the nuke lands where you click, and cars and planes drive / fly that way. Each one is used once. Every turkey it gets pays you the same coins as catching it yourself.

🔫 Guns

Get turkeys from far away! Guns go into your hotbar too. Hold one, then click (or tap) the map to shoot where you aim, or press F / 🔥 FIRE to auto-aim at the nearest turkey. A gun disappears when it runs out of ammo. Buying the same gun again adds more ammo.

🛡️ Armour protects you from other players on the server: it soaks up damage before your health does (the blue bar). You put it on as soon as you buy it, and you lose it when you're eliminated. Buying a better one tops you up to that much armour. Other players can see your armour on you — unless you buy 👻 Invisible Armour.

🦃 You're a turkey, so this shop only sells slime and traps to slow the hunter down! They go into your hotbar: hold one and click the map to put it there (close to you) — then lead the hunter over it. The Slime Ball flies straight at him.
